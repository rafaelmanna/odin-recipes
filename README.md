Odin Recipes

A simple recipe website built as part of The Odin Project Foundations course.
This project features a collection of traditional Brazilian recipes presented in English, including:

- Brigadeiro
- Pão de Queijo
- Coxinha
- Paçoca

Features
- Semantic HTML structure
- Accessible image descriptions (alt text)
- Internal navigation between pages
- Recipe descriptions, ingredients, and preparation steps
- Git and GitHub version control
- Deployed with GitHub Pages

Technologies Used
- HTML5
- Git
- GitHub
- GitHub Pages

Live Preview -> https://rafaelmanna.github.io/odin-recipes/

Through this project I practiced:
- Creating and organizing multi-page websites
- Working with semantic HTML elements
